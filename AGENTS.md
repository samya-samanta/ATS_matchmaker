# Project working guidelines

The user requested the [Karpathy guidelines](https://github.com/multica-ai/andrej-karpathy-skills/blob/main/skills/karpathy-guidelines/SKILL.md). Apply these principles in this project:

- State material assumptions and ask concise questions when ambiguity affects the result.
- Prefer the simplest solution that meets the request; avoid speculative features.
- Keep changes focused on the requested task and preserve unrelated work.
- Define observable success criteria, verify them, and report limitations honestly.

For résumé work, preserve wording and factual claims when only formatting is requested. Verify the rendered PDF page count and check for lost text or poor page breaks. Never claim an employer ATS score or a verified job match without supporting evidence.
